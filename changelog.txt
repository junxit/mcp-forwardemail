  `token` argument and calls GET /v1/domains/{domain}/invites/{token}

- Added: domain_test_s3_connection to validate custom S3 storage credentials

  - Calendar events: calendar_events_list, calendar_event_create/get/update/delete
  - Messages: messages_list, message_create/get/update/delete
  - Folders: folders_list, folder_create/get/update/delete
  - Sieve scripts: sieve_scripts_list, sieve_script_create/get/update/delete/activate

- Changed: Tool count grew from 31 to 71
- Changed: Removed the global Content-Type request header so httpx sets it per
  request (form for data, application/json for JSON bodies) - required for the new
  JSON endpoints; existing form endpoints are unchanged
- Changed: Bumped version to 0.2.0 (pyproject.toml and __init__.py had lagged at
  0.1.0 behind the 0.1.1 changelog entry; now realigned)

  the content-type fix, and tool/handler wiring
